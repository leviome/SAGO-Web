# Virtual Drone

本文描述 [SAGO（ECCV 2026）](https://arxiv.org/abs/2607.01628) 相关能力在 Web 端的移植；论文与浏览器实现的范围及引用见 [PAPER.md](PAPER.md)。

在 SAGO 分割面板中加载模型、点选或框选目标，预览并选择完整的 mask，点击 **Virtual Drone · 自动多视角细化并应用**。无需先点击“记住目标”。使用透视视图，初始画面尽量完整包含对象。模型仍使用原版 SAM2 Hiera Large FP32，全部推理、渲染与 mask 投影在浏览器 WebGPU 上完成，无推理服务。

分割入口会先检查坐标系。点击“选三点校正地面”可启用方向工具，固定以 XZ 网格为地面目标，再用三点对齐校正当前图层。进入分割前必须明确确认 +Y 朝上；采样平面倾角超过 5°、点数不足或共线时不能确认。平面法向有正反两面，因此还需要人工检查场景是否颠倒；应从地面上方取点。旋转相机、修改局部枢轴不会代替真实的图层方向校正。

## 扫描与筛选

以 `sago_core/virtual_drone.py` 的 `spatial_track` 空间细化流程为基准：

1. 用当前 mask 和面板“边缘扩展”参数生成初始视锥，得到可编辑高斯候选。初始视锥不保留画面外的高斯。
2. 用当前选定的候选层重新编码一份提示 memory 和对象指针，分出互相独立的两路历史；两路复用模型会话。按原版 drone 初始化规则，近期队列也以初始 memory 起步。
3. 固定相机到初始目标中心的距离，按 **+45°、−45°、+90°、−90°、+135°、−135°** 扫描，球面仰角 **30°**。每轮用当前三维候选中心重新设置观察目标。两侧渲染同一轮开始时的候选集合。
4. 临时 GPU buffer 只显示候选集合，不修改源实例的选区、锁定、删除或变换状态。其他图层不进入巡航推理图。所有离屏截图使用排序透明混合，避免随机透明渲染影响 mask 和覆盖率。
5. SAM2 融合该方向的历史，以 level 1–3 中最高评分的 mask 跟踪。通过 SuperSplat WebGPU 按高斯中心投影并取交集。扩展后 mask 接触画面边缘时，保留该视角画面外的已有候选。
6. 回到初始相机渲染新候选，用 alpha > 0.3 得到轮廓，计算 **交集面积 / 初始 mask 面积**。只有覆盖率至少 **80%** 的非空结果才被接受。目标丢失、空 mask 或覆盖不足时保留上一步候选，继续扫描。
7. 六个视角完成后恢复初始相机和手动 memory，按面板的替换 / 加入 / 减去 / 取交集模式提交一次编辑。支持一次撤销和重做。结果显示通过视角数及三维候选数的变化。

界面显示 0–6 的进度和当前处理状态，预览巡航画面及 mask。点击“取消巡航”、顶部返回按钮或 Esc 可请求取消；已提交的 GPU 运算结束后恢复状态，不提交中间选区。场景、当前图层或视口尺寸变化会丢弃此次结果。

## 与桌面版的边界

- 使用 SuperSplat 场景的 **+Y** 作为上方向；需要先把场景方向摆正。初始中心用初始 mask 内至多约 256 个网格采样点的渲染深度均值估计；没有有效深度时回退到三维候选均值。后续各轮使用候选高斯中心均值。中心统计在 CPU 上进行，并正确处理实例映射及图层 / 单高斯变换。
- 使用 SuperSplat 的 Gaussian 渲染 alpha 作为原版 `render_mask` 的轮廓近似；两种渲染器并非数值等价。80% 是原版的 `ioi=True` 阈值，不是 IoU，也不是跟踪准确率。
- 为避免错误记忆累积，仅通过自验证的视角才写入对应方向的 memory。原版部分路径在筛选前写入。原版 memory 和指针容量规则保持不变。
- 当前实现采用核心 `spatial_track` 的六视角方案；不包含旧 `tag_widget` 路径的 ±20° 预热、自动框提示增强、BEV 补分割或动态 TAG。不会把两路巡航历史合并到时间序列 memory；手动确认的对象 memory 在运行后恢复。
- 多视角交集只能去除初始候选，不能找回初始 mask 未包含的对象部分。严重遮挡、外观变化或初始 mask 过小仍会影响结果。

## 验证与诊断

`npm run test:sago` 覆盖覆盖率定义与阈值、边界保留、候选单调收紧和中心统计。`npm run test:browser` 使用真实 Chrome WebGPU 推理，覆盖六视角扫描、取消、相机与 memory 恢复、一次撤销 / 重做，以及两个对象沿视线重叠时的背景剔除。

2026-09-23，Chrome / RTX 4090 实测：

- 正面示例：6/6 视角通过，保留目标的 3,000 个高斯。
- 两对象沿视线重叠：初始 6,000 个候选，经 ±45° 两个视角收紧至 3,000；后四个视角目标丢失，保留已接受结果。
- 取消后相机姿态、选区标志和手动 memory 恢复；成功提交只需一次撤销即可还原。
- 11 项单元测试通过，3 项浏览器测试通过，1 项需要外部真实 PLY 的可选测试跳过；typecheck、lint、build 通过。这些是功能验证，尚不能代表复杂真实场景的准确率。

运行后重新打开分割面板并导出诊断 JSON，`virtualDrone` 保留最近一次完整扫描的角度、接受 / 拒绝原因、覆盖率和剩余候选数。它是上次扫描报告，不代表新捕获图像的预测；不含完整 memory 张量，不能单独用来重放模型。
